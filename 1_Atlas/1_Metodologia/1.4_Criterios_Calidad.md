# Criterios de Calidad

## Todo proyecto deberá cumplir:

- Arquitectura consistente.
- Documentación actualizada.
- Ausencia de duplicación.
- Convenciones respetadas.
- Cambios trazables.
- Auditorías documentadas.
- Código mantenible.
- Recursos organizados.

---

# Indicadores

Durante las auditorías se evaluarán:

- Organización.
- Consistencia.
- Reutilización.
- Complejidad.
- Cobertura documental.
- Trazabilidad.
- Mantenibilidad.

---

# Objetivo

Garantizar que el proyecto pueda mantenerse durante años con el menor esfuerzo posible.
