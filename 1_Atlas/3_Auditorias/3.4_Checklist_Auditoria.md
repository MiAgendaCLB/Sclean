# Checklist de Auditoría

## Objetivo

Disponer de una lista de verificación estándar para cualquier auditoría realizada dentro del ecosistema Atlas.

---

# Documentación

- [ ] Existe documentación oficial.
- [ ] La documentación está actualizada.
- [ ] No existen documentos duplicados.
- [ ] Existe una única fuente de verdad.

---

# Arquitectura

- [ ] La arquitectura está documentada.
- [ ] No existen dependencias innecesarias.
- [ ] Se respetan los principios arquitectónicos.
- [ ] Existe separación de responsabilidades.

---

# Modelo de Datos

- [ ] No existen duplicidades.
- [ ] Las relaciones son consistentes.
- [ ] Los catálogos están centralizados.

---

# Implementación

- [ ] No existe código duplicado.
- [ ] Existe reutilización.
- [ ] La complejidad es aceptable.
- [ ] La solución es mantenible.

---

# Experiencia de Usuario

- [ ] Navegación consistente.
- [ ] Formularios homogéneos.
- [ ] Tablas consistentes.
- [ ] Mensajes uniformes.

---

# Gestión

- [ ] Existe trazabilidad.
- [ ] Los cambios están registrados.
- [ ] El backlog está actualizado.
