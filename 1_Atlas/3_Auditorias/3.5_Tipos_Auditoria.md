# Tipos de Auditoría

## Objetivo

Clasificar las auditorías utilizadas dentro del ecosistema Atlas.

---

# Auditoría Arquitectónica

Evalúa:

- arquitectura;
- dependencias;
- modularidad;
- cohesión.

---

# Auditoría Funcional

Evalúa:

- requisitos;
- comportamiento;
- casos de uso.

---

# Auditoría Técnica

Evalúa:

- código;
- rendimiento;
- mantenibilidad.

---

# Auditoría Documental

Evalúa:

- documentación;
- consistencia;
- cobertura.

---

# Auditoría de Datos

Evalúa:

- modelo de datos;
- integridad;
- relaciones.

---

# Auditoría UX

Evalúa:

- navegación;
- usabilidad;
- coherencia visual.

---

# Auditoría Integral

Combina todas las anteriores.
