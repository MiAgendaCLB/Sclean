# Prioridades

## Objetivo

Definir una clasificación uniforme para todos los hallazgos.

---

# P1 — Crítica

Impide el funcionamiento del proyecto.

Debe atenderse inmediatamente.

---

# P2 — Alta

Afecta arquitectura, integridad o mantenibilidad.

Debe atenderse en el corto plazo.

---

# P3 — Media

Mejora importante.

Puede planificarse.

---

# P4 — Baja

Optimización.

No afecta el funcionamiento.

---

# P5 — Observación

Idea documentada.

No constituye una necesidad inmediata.
