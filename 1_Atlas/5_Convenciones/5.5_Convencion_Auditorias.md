# Convención de Auditorías

## Objetivo

Definir un proceso uniforme para todas las auditorías realizadas dentro del ecosistema Atlas.

---

# Finalidad

Una auditoría existe para verificar.

Nunca para modificar.

---

# Tipos

- Arquitectura.
- Funcional.
- Técnica.
- UX.
- Datos.
- Documentación.
- Código.
- Rendimiento.

---

# Hallazgos

Todo hallazgo deberá contener:

- prioridad;
- descripción;
- evidencia;
- impacto;
- causa;
- solución propuesta;
- riesgo de implementación.

---

# Evidencia

No deberán emitirse conclusiones sin evidencia.

Si la evidencia es insuficiente deberá indicarse expresamente.

---

# Resultado

La auditoría únicamente puede:

- aprobar;
- rechazar;
- solicitar mayor evidencia.

Nunca implementará cambios.

---

# Relación con Gestión de Cambios

Todo hallazgo aprobado iniciará un proceso de Gestión de Cambios.

La auditoría termina cuando concluye la verificación.

La implementación pertenece a otro proceso.
