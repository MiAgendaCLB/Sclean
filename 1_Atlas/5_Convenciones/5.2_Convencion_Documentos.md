# Convención de Documentos

## Objetivo

Establecer una estructura uniforme para todos los documentos del ecosistema Atlas.

Estas reglas aplican a cualquier proyecto que utilice esta metodología.

---

# Principios

Todo documento debe cumplir los siguientes principios:

- Tener un único propósito.
- Evitar duplicar información existente.
- Ser fácil de localizar.
- Poder evolucionar sin romper referencias.
- Poder leerse de forma independiente.

---

# Nombre del archivo

Los nombres deberán ser descriptivos.

Ejemplo:

Convencion_Documentos.md

Arquitectura_General.md

Modelo_Datos.md

No utilizar:

Documento1.md

Notas.md

Varios.md

Nuevo.md

---

# Numeración

La numeración pertenece a la carpeta.

No al documento.

Correcto:

5_Convenciones

Convencion_Documentos.md

Incorrecto:

05_Convencion_Documentos.md

5.2_Convencion_Documentos.md

La ubicación del documento ya proporciona el contexto suficiente.

---

# Contenido

Cada documento deberá responder únicamente una pregunta.

Ejemplos:

¿Cómo se nombran las carpetas?

¿Cómo se documentan los cambios?

¿Cómo funciona la auditoría?

Nunca responder varias preguntas distintas en un mismo documento.

---

# Modificaciones

Cuando un documento cambie:

- actualizar el documento completo;

o

- continuar mediante una Parte claramente identificada.

Nunca crear:

Convencion_Documentos_v2.md

Convencion_Documentos_Final.md

Convencion_Documentos_Nuevo.md

---

# Estado

Los documentos podrán encontrarse en uno de los siguientes estados:

Borrador

En Consolidación

Oficial

El estado deberá aparecer al inicio del documento.

---

# Fuente Oficial

Cada tema tendrá un único documento oficial.

Si existe un documento oficial:

no deberá crearse otro equivalente.

---

# Referencias

Cuando un documento dependa de otro:

se hará referencia a la ruta del documento.

No se duplicará el contenido.

---

# Compatibilidad

Todos los documentos deberán utilizar Markdown estándar.

No dependerán de funciones exclusivas de Obsidian.

Deberán poder visualizarse correctamente desde:

- Obsidian
- GitHub
- Visual Studio Code
- cualquier editor Markdown compatible.
