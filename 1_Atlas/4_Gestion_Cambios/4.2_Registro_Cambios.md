# Registro de Cambios

## Objetivo

Mantener el historial oficial de todos los cambios realizados dentro del ecosistema Atlas.

Este documento constituye la fuente oficial para consultar la evolución de cualquier proyecto.

---

# Información mínima

Todo registro deberá contener:

- Identificador.
- Estado.
- Proyecto.
- Documento afectado.
- Descripción.
- Evidencia.
- Fecha.
- Resultado.

---

# Formato

| ID | Estado | Proyecto | Documento | Descripción | Evidencia | Fecha |
|----|---------|----------|-----------|-------------|-----------|-------|

---

# Estados Permitidos

- H
- HV
- HVC
- HVCA
- HN

---

# Reglas

- No eliminar registros.
- No modificar identificadores.
- No reutilizar numeración.
- Registrar únicamente hechos verificables.
- Mantener orden cronológico.

---

# Observaciones

El Registro de Cambios permite reconstruir completamente la evolución de un proyecto y sirve como insumo para auditorías, documentación y control de versiones.
