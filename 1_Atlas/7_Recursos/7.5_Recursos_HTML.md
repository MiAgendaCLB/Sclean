# Recursos HTML

## Objetivo

Centralizar las reglas para el desarrollo de aplicaciones HTML autocontenidas.

---

# Principios

- Un único archivo HTML.
- CSS integrado.
- JavaScript integrado.
- Sin dependencias externas cuando sea posible.
- Compatible con navegadores modernos.

---

# Buenas prácticas

- Código modular.
- Funciones pequeñas.
- Variables con nombres claros.
- Componentes reutilizables.

---

# Restricciones

No utilizar librerías externas salvo que exista una justificación documentada.

---

# Referencias

Las reglas específicas de cada proyecto deberán documentarse dentro del mismo proyecto.
