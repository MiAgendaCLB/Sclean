# Reglas Funcionales

## Principios Generales

Sclean toma decisiones únicamente cuando existen reglas objetivas para hacerlo.

Cuando la información es insuficiente solicita intervención del usuario.

Nunca realiza interpretaciones.

Nunca realiza inferencias clínicas.

---

# Integridad Documental

El contenido del documento siempre prevalece sobre cualquier procesamiento automático.

La restauración nunca modifica el significado del documento.

---

# Automatización

El sistema automatiza todas las tareas repetitivas.

El usuario únicamente interviene cuando:

- existe incertidumbre;
- existen varias opciones válidas;
- la clasificación no puede resolverse automáticamente.

---

# Clasificación

La clasificación depende exclusivamente del contenido documental.

Nunca depende de:

- nombre del archivo;
- carpeta;
- fecha de creación del archivo;
- fecha del sistema operativo.

---

# Segmentación

La segmentación siempre es documental.

Nunca física.

El cambio de página no implica un nuevo documento.

El cambio de diseño no implica un nuevo documento.

---

# Restauración

Solo se restauran documentos cuya calidad pueda mejorarse.

Los documentos con calidad adecuada permanecen prácticamente sin cambios.

---

# OCR

El OCR nunca reemplaza el contenido visual del documento.

Únicamente genera una capa de texto para facilitar búsquedas y clasificación.

---

# Nomenclatura

Toda nomenclatura proviene exclusivamente del contenido documental y de los catálogos oficiales.

Nunca se generan nombres utilizando información externa.

---

# Exportación

Todo documento exportado debe cumplir:

- integridad documental;
- clasificación válida;
- nomenclatura oficial;
- trazabilidad completa.

Solo entonces se considera preparado para Vive.
