# Objetivos

## Objetivo General

Preparar automáticamente documentos digitales para que puedan ser incorporados a Vive con la menor intervención posible del usuario.

---

## Objetivos Específicos

- Detectar automáticamente la calidad documental.
- Restaurar únicamente cuando sea necesario.
- Extraer texto mediante OCR cuando el documento no disponga de una capa de texto.
- Identificar correctamente los documentos contenidos dentro de un archivo.
- Separar cada documento respetando su integridad documental.
- Clasificar automáticamente cada documento.
- Generar una nomenclatura oficial.
- Detectar posibles duplicados.
- Solicitar confirmación únicamente cuando exista incertidumbre.
- Generar documentos independientes listos para Vive.

---

## Objetivos de Calidad

Todo documento generado deberá cumplir las siguientes condiciones:

- Mantener exactamente el mismo contenido del original.
- No inventar información.
- No eliminar información.
- Ser completamente legible.
- Mantener la estructura documental.
- Poder ser localizado mediante su nomenclatura.
- Poder ser procesado automáticamente por Vive.

---

## Objetivos de Usabilidad

El usuario deberá poder completar el proceso con el menor número posible de decisiones.

El sistema automatizará toda tarea repetitiva.

Las decisiones manuales se limitarán a los casos donde exista incertidumbre.

---

## Objetivos Técnicos

La aplicación deberá:

- funcionar completamente de forma local;
- no depender de servicios en línea;
- conservar siempre el documento original;
- producir resultados reproducibles;
- registrar todas las operaciones realizadas.
