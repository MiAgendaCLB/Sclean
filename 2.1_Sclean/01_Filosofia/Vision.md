# Visión

Sclean existe para eliminar el trabajo repetitivo asociado a la preparación documental.

El usuario no debe preocuparse por:

- calidad del escaneo;
- OCR;
- rotación;
- separación de documentos;
- clasificación;
- nomenclatura.

Su única responsabilidad consiste en entregar los archivos.

Sclean realizará automáticamente todas las tareas necesarias para producir documentos preparados para Vive.

La simplicidad para el usuario es el resultado de ocultar la complejidad técnica del sistema.

Toda decisión automática debe ser verificable.

Toda decisión incierta debe solicitar confirmación.

Nunca debe inventarse información.

Nunca debe alterarse el contenido documental.

La prioridad del proyecto es la confiabilidad antes que la automatización.
