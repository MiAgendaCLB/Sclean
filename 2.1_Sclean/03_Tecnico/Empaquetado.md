# Empaquetado

## Objetivo

Distribuir Sclean como una aplicación local lista para ejecutar.

---

# Distribución

La distribución incluye:

- ejecutable;
- base de datos inicial;
- catálogos;
- Tesseract;
- Ghostscript;
- qpdf;
- recursos internos.

---

# Requisitos

No requiere:

- Internet;
- servidor;
- instalación de Python;
- instalación de SQLite.

---

# Actualización

Las actualizaciones consisten en reemplazar la carpeta de distribución por una versión más reciente.

Los documentos del usuario permanecen independientes de la aplicación.

---

# Compatibilidad

La arquitectura permite incorporar nuevas dependencias sin modificar la estructura general del sistema.
